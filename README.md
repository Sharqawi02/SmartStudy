# SmartStudy

Project scaffold with:
- `backend/` using Python Flask
- `frontend/` using React + Vite

## Backend (Flask)

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Runs on `http://127.0.0.1:5000`.

## Frontend (React + Vite)

```bash
cd frontend
npm install
npm run dev
```

Runs on `http://127.0.0.1:5173`.
